# Анализ рынка вакансий для Data / System Analyst

## Цель проекта
Изучить рынок труда для аналитиков данных и системных аналитиков на основе данных парсинга вакансий: 
определить уровень зарплат, востребованные грейды, ключевые навыки и ведущих работодателей.

## Инструменты
- **PostgreSQL** — обработка и анализ данных
- **Git / GitHub** — версионирование

## Структура проекта
- `queries.sql` — все SQL-запросы с комментариями

## Этапы анализа

### 1. Диапазон заработных плат
- Средняя зарплата «от»: **109 525 руб.**
- Средняя зарплата «до»: **153 846 руб.**
- Средний диапазон: **~130 000 руб.**
- Минимум: 50 руб. (вероятно, ошибка парсинга)
- Максимум «до»: **497 500 руб.**

### 2. География вакансий
- **Лидеры:** Москва и Санкт-Петербург
- Также высокая активность: Екатеринбург, Нижний Новгород, Новосибирск

### 3. Ведущие работодатели
- **Сбер** — 187 вакансий в Москве (лидер)
- **Wildberries**, **Ozon** — активные наниматели

### 4. Типы занятости
- **Полная занятость:** 1764 вакансии (~85%)
- **Удаленная работа:** 310 вакансий
- Проектная работа — минимальный спрос

### 5. Распределение грейдов
| Грейд | Доля |
|-------|------|
| Junior+ (1–3 года) | **64.40%** |
| Middle (3–6 лет) | 26.02% |
| Intern | 9.13% |
| Senior (6+ лет) | 0.45% |

### 6. Топ навыков
1. Анализ данных — 312 упоминаний
2. SQL — 161
3. Документация — 89
4. MS SQL — 87

## Ключевые выводы
- Рынок ориентирован на **специалистов начального и среднего уровня** (Junior+/Middle — 90% вакансий).
- **SQL и анализ данных** — обязательные навыки для аналитика.
- Большинство вакансий — **полная занятость в Москве**.
- **Сбер** — крупнейший работодатель в нише.
